## Gotchas — verified; do not rediscover these the hard way

- **Legacy tier semantics differ per language.** Python L1 = hex rename; JS L1 = hex *literals* + member-string rewrite. Python L2 = sequential `state_N` while-machine; JS L2 = object-dispatch table + dead code + string table. This is why the new conditions live in their own namespace (`docs/TIER_MAPPING.md`).
- ⚠️ **Legacy ICSE JS L2/L3 rows contain H1-family features** (string-keyed dispatch tables). They are never trainable and never usable in an "unseen transform" claim; `scripts/check_manifest.py`'s marker scan catches them if they ever leak in.
- **Dataset A Python rows carry human-formatted I/O** (`inputs: "myFunct(6)"`, `outputs: "FALSE"`) and the code is double-spaced (a survey-presentation artifact). Canonical outputs are re-derived by execution; the human key is kept verbatim and disagreements are logged to `manifests/testset_ingest_report.json`.
- **The archived L1b mapping parquets in `transcoders/data/stimuli/alignment/` are from a different L1b generation round** than the study stimuli (`fibfib→rns` vs `fibfib→smoothArea`, ~0/10 match). Never use them; derive mappings cross-tier from the stimuli themselves, as `transcoders/src/convert_stimuli.py` does.
- **SFR embeddings are not on this host** — semantic-displacement measures exist only as proxies in `model_understanding_dualsystem/stats/data/canonical/adv.parquet`.
- The obfuscation pipeline architecture was ported from `allocation_replication/pipeline/obfuscation/` (Java-only); the transform code itself is new.
